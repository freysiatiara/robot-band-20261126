# Name the Robot Band

One funny name for a band made of robots, plus a few words on its hit song — all under 200 characters.

## The entry

> The Captchas — hit single 'Prove You're Human' is the only number one no robot has ever been allowed to stream.

A band of robots whose hit song is a test no robot can pass — and no robot is allowed to stream it.

## How it works

`main.py` (Python standard library only) writes the line above to the output path resolved as `ENTRY_OUTPUT`, else `OUTPUT_DIR` or `MAKEFUN_OUTPUT_DIR` joined with `entry.txt`, else `/output/entry.txt`, else the script's own directory. It enforces the 1–200 character gate, writes with a plain `open`/`write` (no tempfile), and sets the output mode to `0644`. No trailing newline.
